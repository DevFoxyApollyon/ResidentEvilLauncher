# Resident Evil Launcher (RE Hub)


**[Todas as versões jogáveis e como instalar cada uma](VERSOES.md)**

Todos os Resident Evil em um lugar só, no estilo da tela inicial do PS5, para Windows.

- Linha do tempo em ordem da história, spin-offs, versões perdidas e betas, filmes, HQs e livros, projetos de fãs e notícias (REVIL).
- Jogos da Steam com capas, logos, troféus, DLCs e trailer numa telinha; clássicos por emulador, decomps e recomps.
- Mods pelo [Fluffy Mod Manager](https://www.fluffyquack.com/) (baixado e aberto pelo app), com atalho para o REFramework nightly.
- Tela de carregamento, sons de interface, trilha por jogo (com os arquivos que **você** colocar) e fonte do título parecida com a de cada jogo.
- O mesmo programa serve para outras franquias (ex.: Silent Hill) trocando o `franquia.json` e o catálogo.

## Rodar

```
pip install -r requirements.txt
python main.py
```

Documentação completa (em português): [LEIA-ME.md](LEIA-ME.md).

## O que não vem no repositório

Músicas, sons, capas, trailers e ferramentas de terceiros não são distribuídos aqui. O app baixa as artes e os
trailers das lojas na primeira vez, e as músicas são as que você colocar em `data/musica/<jogo>/`.
Resident Evil é marca da Capcom; este é um projeto de fã, sem ligação com a Capcom.
